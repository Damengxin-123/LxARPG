# 技能流程体系

## 正式技能

正式流程位于内容浏览器 `项目内容/数据资产/技能流程`。`项目内容/数据资产/数据表格/物品信息/技能/技能数据表` 中 15 个已有实现的物品已直接引用以下 12 个流程；原物品标签、图标、描述、价格等信息保持原样。

| 流程 | 有效执行链 |
| --- | --- |
| 火球术 | 直线火球命中→缩放范围爆炸命中→燃烧异常；前两段保留原词条 0，燃烧每秒造成 1 点基础火焰伤害 |
| 火焰爆弹 | 抛射火球命中后创建缩放范围 |
| 火焰跳蛋 | 弹跳火球命中后创建缩放范围 |
| 冰锥术 | 直线冰锥命中后施加周期依附，依附使用原词条 0 |
| 火焰射线 | 单次射线命中后创建缩放范围 |
| 火焰喷射 | 按住维持射线，命中后创建自主缩放范围，松手结束射线 |
| 火之领域 | 同时创建周期伤害光环与自身护甲光环，持续 10 秒 |
| 衰弱领域 | 创建持续 10 秒的护甲削弱光环 |
| 厄运诅咒 | 冰锥命中→周期依附→目标位置范围效果→向目标发射冰锥，最后一段使用词条 0 |
| 宝箱怪范围攻击 | 释放锚点创建直接范围，使用原词条 0 |
| 复合测试 | 火球命中→直接范围命中→单次射线 |
| 光环测试 | 创建原有无限持续的周期光环 |

迁移逐字段读取旧蓝图引脚中的速度、距离、加速度、弹跳、重力、持续时间、间隔、创建位置、方向、目标筛选和命中限制，并复制词条包。旧图未连接的实验节点不进入有效流程。所有形态都可通过“覆盖单元目标规则”使用节点的筛选和命中限制；直线投射物与缩放范围始终使用节点规则。

保留的旧配置情况：冰锥术投射物调用的词条下标 2 原本越界，迁移为不触发词条；其周期依附仍使用词条 0。爆弹、跳蛋和射线原图没有连接伤害词条，不在迁移中自动补伤害。`新增_冰锥术` 行原本绑定火球术，本次保留该绑定。召唤骷髅等 9 行原本没有技能实现，继续作为未实现占位。

旧技能蓝图保留作参考，正式运行链路不再使用它们。运行对象只接受流程资产；未配置流程的物品不会创建技能对象，释放模块也拒绝没有流程的对象。技能类型不再允许新建蓝图子类。

迁移工具 `LxSkillFlowMigration`：无参数导出旧图审计；`-Apply` 创建缺失的正式流程并修改技能表；`-Verify` 从磁盘重新加载，对照旧蓝图检查参数、词条、节点连线及物品绑定。已有流程若与迁移源不同则报错，不覆盖后续编辑。迁移前技能表备份位于 `Saved/SkillMigration/备份/技能数据表.uasset`，报告位于同目录上一级的 `迁移结果.txt` 和 `迁移验证.txt`。

编辑器模块使用 `PreDefault` 加载，确保正式物品表在启动时引用流程资产之前，图节点类型已经注册；游戏运行仍只依赖流程的运行数据。

## 独立示例

内容浏览器打开 `项目内容/测试/技能流程`，双击“火球流程”“喷射流程”或“蓄力流程”查看图形编辑器。

| 流程资产 | 技能物品示例表行 | 示例行为 |
| --- | --- | --- |
| 火球流程 | 火球流程 | 直接释放自主火球，命中后创建范围效果 |
| 喷射流程 | 喷射流程 | 同时创建自主火球和维持射线，松手只结束射线 |
| 蓄力流程 | 蓄力流程 | 结束蓄力后发射火球，命中后创建范围效果 |

同目录的“流程技能物品”数据表直接引用以上流程。示例表仅供对照配置，复用现有标签但不注册进正式物品配置，避免与已有技能重复。示例复用项目现有的火球、范围和射线单元蓝图，未配置伤害词条。喷射示例使用持续射线表现来验证按住维持的规则。

## 编辑和接入

1. 在内容浏览器右键的玩法资产分类中创建“技能流程”。
2. 右侧配置“释放方式”和“攻击动作类型”。当前不配置技能 CD，释放速度由动画及释放状态控制。
3. 在画布空白处右键添加角色事件或技能单元，拖动引脚连接流程。
4. 选中单元后，在中间参数面板配置单元蓝图、维持方式、创建位置以及对应类型的参数。
5. 将事件的“执行”出口连接单元的“创建”入口。单元的“命中”出口每次命中都会触发；“结束”出口在整组单元结束时触发。
6. 等顶部提示“配置有效”后保存。在技能物品数据表行中，将“技能流程”设为该资产，即可沿用项目原有的背包、快捷栏和释放入口，无需创建配套技能类型蓝图。

“直接释放”“开始持续释放”和“结束蓄力”仍由现有动作动画的释放通知驱动。松手或打断沿用技能释放模块的正常结束与取消入口。流程中的攻击动作类型交给角色动画系统选择具体动画。

载入物品只保存静态配置，首次使用才创建通用技能运行对象；该对象由物品缓存，保存蓄力和持续释放状态。每次释放仍建立独立流程实例，保证旧火球不受下次释放影响。未使用过的物品调用“获取技能对象”会返回空；确需执行时使用“获取或创建技能对象”。

技能动画结束（或收到动画中的结束通知）后立即允许下一次释放，不再额外等待 CD。按住直接释放技能时，快捷栏每帧检查一次释放组件是否空闲。持续技能仍占用到松手或取消。旧蓝图冷却接口仅保留兼容壳，已标记弃用且不再计时；子单元内部的周期触发和单目标触发间隔仍独立生效。

物品只使用流程，不执行旧技能蓝图事件。旧的技能类型引用仅供迁移工具读取，不在物品配置面板显示，也不作为运行时回退入口。

## 子单元可视化名称

子单元蓝图的“类默认值 → 技能单元 → 描述 → 可视化名称”用于配置统一的显示名称，使用可本地化的文本。单元节点直接显示所选子单元的名称，下方显示形态和维持方式，不再提供单独的“节点名称”字段。未填写可视化名称时显示蓝图类型名称（去掉生成类的 `_C` 后缀）；未选择类型时仍显示节点形态。事件节点直接显示事件名称。

后续生成技能描述时，可以使用“获取技能子单元类型可视化名称”从类型读取名称，无需生成场景实体；已有实例可调用“获取技能子单元可视化名称”，流程节点配置可调用“获取流程子单元可视化名称”。名称保存在运行时数据中，不依赖编辑器标签。

## 元素异常依附

在画布右键选择“技能单元 → 依附效果 → 元素异常依附”，把前置单元的“命中”出口接入其“创建”入口。直接释放事件和结束出口不能作为异常依附的输入。

节点参数可配置：持续时间、触发几率（0～100%）、异常状态标签、维持 Buff 列表及其效果比例、每次基础伤害、伤害类型、伤害间隔、异常视觉效果（Niagara 粒子资源）。状态、Buff、周期伤害至少配置一项；Buff 标签必须已登记在项目 Buff 物品表中。类型留空使用原生异常依附单元，也可以选择它的蓝图子类补充表现，蓝图覆盖激活时应调用父类实现。

每次上游命中会为每个不同目标创建一个单元，每个单元只在服务端首次激活时判定一次几率。0% 必定失败，100% 必定成功；失败立即销毁，不施加状态、Buff，不启动周期伤害或播放粒子。成功后依附角色光环锚点，通过目标效果传递模块施加配置，并输出一次“命中”。节点“结束”出口仍按整组单元结束触发，不表示所有目标都成功施加了异常。

默认使用“自主运行”，前置单元销毁或释放动作结束后仍持续。持续时间小于等于零表示持续到停止、取消、目标死亡或销毁；有限时间由依附生命周期组件结束。Buff 倒计时只用于显示，来源维持型 Buff 不会自行过期。单元到期、取消、直接销毁、目标死亡或世界退出时撤回本实例贡献。

当前采用独立实例：同种异常可同时存在，每个实例分别计时造成伤害并持有可选的属性 Buff，状态标签合并显示；一个结束不会清除另一个，也不会清除普通状态接口直接添加的标签。普通计时 Buff 仍按原规则工作，不与异常维持型实例合并。尚未加入免疫、抗性、刷新叠层或根据伤害元素自动触发的配置表；本阶段由技能图明确连接异常节点。状态标签本身不自动禁止移动或释放技能，具体减益由配置的 Buff 和已有状态消费者决定。

正式火球术已配置“缩放范围爆炸的命中 → 元素异常依附（燃烧）”，触发几率 100%，持续时间 5 秒，自主运行。异常维持 `角色状态.元素异常状态.燃烧`，由技能单元每 1 秒直接造成 1 点基础火焰伤害。燃烧节点的维持 Buff 列表为空，也不重复投递火球伤害词条包。

周期伤害复用生命周期组件的周期事件；首次等待完整间隔，最小间隔 0.1 秒。“每次基础伤害”设为 0 可关闭伤害，保留状态或属性 Buff。正数伤害需要配置 `通用效果.伤害效果` 下的具体类型。火球使用 `通用效果.伤害效果.火焰伤害`，无需另建扣血词条或 Buff。上一版 Buff 表“燃烧”行及属性回复词条表“燃烧扣血”行已移除；旧标签仅保留兼容标识。

每个周期由异常单元构造伤害效果包，保留施法者与异常单元来源，经过施法者“构建输出效果包”及目标“接收效果包”，使用全局配置的伤害计算流程。当前原生流程包括输出暴击、防御减伤、护盾优先结算和受伤事件；未额外实现按元素区分的抗性。周期结算不会重复广播技能图的“命中”出口。到期先结算恰好落在终点的周期，再撤回状态与可选 Buff；取消、目标死亡、直接销毁或世界退出后停止伤害。施法者已销毁时仍用固定基础伤害走目标承伤流程。

“1 点”现在表示基础伤害，实际扣血受输出计算、防御和护盾影响。项目现有资源系统还会对最终生命值取整，低伤害经过减免后可能表现为 0 扣血；本次保留这一规则。Buff 继续用于配置属性增益或减益，不作为本次燃烧伤害的中转对象。

视觉复用项目的 `NS_Fire_Castle_01_NoSmoke` 火焰 Niagara 系统，使用软引用，在实际激活时加载，避免项目启动加载数据表时提前加载特效模块。无渲染测试仅检查资源可加载以及效果清理，未检查最终粒子尺寸和画面。

`新增_冰锥术` 目前也引用火球术流程，会一并获得燃烧，现有绑定保持不变。`LxSkillFlowMigration -Verify` 是与旧蓝图的原始迁移对照，新增燃烧后火球流程与旧图存在预期差异；请使用 `LxARPG.SkillFlow.ElementAbnormal.FireballBurn` 检查现在的正式配置。必要时可在备份后用 `-run=LxFireballBurn -Apply` 重新配置；工具会复用已有燃烧节点，并清理上一版燃烧专用扣血表行。

验证入口为 `LxARPG.SkillFlow.ElementAbnormal`，覆盖真实目标状态、Buff 来源隔离、概率边界、到期和销毁清理、图连接校验与多目标流程；`FireballBurn` 还从磁盘加载正式火球资产，验证爆炸命中、无 Buff 的周期伤害和终点清理；`DamagePipeline` 检查输出暴击、防御减伤、护盾结算、取消重入、零概率不伤害及现有整数资源规则。无渲染自动化验证逻辑和表现组件的激活门槛，粒子的实际外观仍需在选择具体资源后预览。

## 生命周期规则

- 自主运行：创建后不再接收角色的停止、取消和瞄准更新通知。命中、最大飞行距离或单元自身完成逻辑决定结束时刻。
- 随本次释放维持：接收正常停止或异常取消通知，由单元自己的实现收尾。此关系不会自动传递给后续节点。
- 结束蓄力会结束蓄力阶段的维持单元，并执行“结束蓄力”入口连接的自主单元。
- 释放结束后，尚未执行的维持节点不再创建；已产生的自主单元和其命中、结束分支继续执行。
- 每次释放拥有独立的节点配置快照、上下文和事件队列，下一次释放不会覆盖旧火球的结果。
- 世界持有执行实例，所有自主单元及后续任务结束后才回收实例。组在单元自行报告完成后清理实体；释放模块不直接销毁它们。

## 可用子单元节点

右键菜单按用途提供全部 19 种具体子单元，每种节点都有对应的类型选择和创建参数，并读取所选子单元的可视化名称。

| 分类 | 节点 |
| --- | --- |
| 投射物 | 直线投射物、地面弹跳投射物、抛射投射物 |
| 范围效果 | 直接命中范围效果、持续范围效果、缩放范围效果 |
| 射线 | 单次射线、持续射线 |
| 近战 | 近战效果 |
| 依附效果 | 持续依附效果、周期依附效果、元素异常依附 |
| 光环效果 | 持续光环、周期光环 |
| 生成实体 | 生成实体、屏障、标记、召唤生物 |
| 触发器 | 触发器 |

依附节点接在前置单元的“命中”出口上，读取该次命中的目标；不使用创建位置。光环依附释放角色的光环锚点，配置中可设置光环范围。维持中的依附与光环也不会被瞄准更新移离其挂接目标。持续依附和持续光环使用持续词条投递，并在单元结束或目标离开时撤销对应效果。

持续射线和近战效果没有内置到期时间，默认并要求“随本次释放维持”，应接开始蓄力或开始持续释放入口。直接释放与结束蓄力分支中的单元必须自主运行。近战节点沿用现有近战单元接口，武器命中检测仍由具体单元蓝图或近战系统接入；生成实体、屏障、标记、召唤生物沿用现有实体载体接口，具体生成和行为由所选子单元蓝图实现。

新建持续范围、缩放范围、依附、光环、实体载体和触发器节点默认持续 5 秒，可在各自参数中修改。抽象形态基类不作为重复节点提供。暂不支持循环、延迟节点、条件节点、蓄力时长映射以及图内实时运行调试。

命中词条包可以在资产中配置，并在节点中选择下标；默认 -1 仅运行形态。伤害仍沿用项目现有的释放者属性及效果投递链路，尚未实现释放者对象销毁后的独立伤害属性快照。

没有指定单元蓝图时使用对应原生类型，但原生类型不自带项目的模型和碰撞体；可视化试用请选择实际子单元蓝图。屏障、标记和召唤生物也会使用各自原生载体，而不是统一退回普通实体载体。范围大小由该蓝图的碰撞体配置。
