# AI控制配置：事件入口第一版

按角色类型（例如宝箱怪）创建一份AI控制配置，统一保存感知能力、事件分析与“入口 → 状态 → 阶段 → 行为”配置，无需为场景中的每个角色单独填写参数。资产只保存共用参数；当前目标、记忆、距离滞回、受击事件与当前分支由每个角色独立持有。

图支持创建、连线、编辑、撤销、保存与重新打开；路线与点位支持场景配置及运行时注册查询。运行时由感知事实和受击通知选择入口、状态与阶段，再按排列序号执行阶段内的行为节点。角色需要配置有效的行为树资产才能启动自动控制。

## 打开与编辑

内容浏览器右键 → 玩法 → **AI控制配置**。新建资产包含五个固定入口、五种普通状态、五个对应阶段和十二种行为，并附加死亡专用状态、阶段和行为，共28个节点。默认生命区间均为 `[0, 1]`，点位、路线和技能 ID 需要按实际内容填写；运行时只执行通过完整配置校验的资产。

编辑器包含“行为配置”“感知能力”“事件分析”面板，可停靠或通过窗口菜单重新打开。后两者分别固定编辑资产的感知与分析参数；选择节点仅切换行为配置中的节点详情。入口的优先级在入口节点详情编辑。

五个入口固定存在、不可删除。右键画布可新增状态、阶段和行为；从输出引脚拖出菜单只列出适用的下一层。多个入口可以共用状态，同分类的多个阶段可以共用行为，阶段仍只属于一个状态。状态和阶段支持多个子项，行为没有子项；拒绝重复边、逆向连接、跨层和跨分类连接。

选中节点后在详情面板配置参数。`Delete` 删除、`Alt+点击引脚` 断线、`Ctrl+Z` 撤销、`Ctrl+Y` 重做、`Ctrl+S` 保存。顶部显示未完成配置或连线错误，允许保存草稿。

状态和阶段的“排列序号”越小越先尝试，相同则按稳定标识排序；拖动画布仅改变布局。阶段内的行为节点按排列序号依次执行；持续入口完成一轮后循环，受击入口完成一轮后结束响应。

## 五入口与分析规则

| 入口 | 激活条件 | 默认优先级 | 默认连接 |
| --- | --- | --- | --- |
| 平静状态 | 没有已知敌人且受击警觉已结束 | 0 | 闲置、巡逻 |
| 发现敌人 | 存在有效已知敌人，包括尚未遗忘的感知记忆 | 100 | 警戒 |
| 敌人靠近 | 已知敌人进入靠近范围 | 200 | 战斗 |
| 受到攻击 | 有效受击触发的一次响应 | 300 | 战斗、逃跑 |
| 角色死亡 | 生命值降为零 | 1000 | 死亡专属状态与阶段中的进入死亡行为 |

入口优先级越大越先检查；角色死亡优先于所有普通事件。普通入口优先级相同时按平静、发现、靠近、受击的固定顺序裁决。生命值降为零时先选中角色死亡入口，执行“进入死亡”后才调用角色原有死亡状态、动画和销毁流程。缺少死亡分支时使用内置默认死亡行为。

“事件分析”提供靠近进入距离（默认5米）、靠近退出距离（默认7米）和受击警觉时间（默认5秒）。进入条件为距离不大于进入距离；进入后，只有超过退出距离才解除，且退出距离必须严格大于进入距离。切换敌人会重置这个滞回状态。分析使用感知提供的最后已知位置，不从记忆目标身上实时读取未感知到的位置。

受击响应选中后保留到消费者完成、其他优先分支接管，或受击入口不再有符合条件的分支。响应期间再次受击只刷新警觉时间，不重启相同状态、阶段，也不排队。状态或阶段因血量改变而切换时可开始新行为。消费者必须确认受击响应完成；警觉时间只控制何时允许恢复平静，不代替响应的完成条件。分析会话也支持不可打断期间保留当前分支，这期间的受击脉冲不延迟重放。

默认模板的生命区间全部重叠，因此闲置先于巡逻，受击后的战斗先于逃跑。配置低血量逃跑时，应调整战斗、逃跑及各自阶段的生命区间，或调整状态排列序号，避免期待默认模板自动推导血量策略。

## 旧图升级

序列化类名和原业务节点标识保持不变。旧资产保留原四入口，编辑器打开时补入角色死亡入口及默认死亡分支。旧状态、阶段、行为及其相互连线、参数和位置保留。

## 角色类型接入

在 `ALxAICharacter` 派生角色蓝图的 Class Defaults（类默认值）中，将“角色配置 → AI → AI控制配置资产”指向配置资产。此引用仅在角色类型上设置，不暴露为场景实例参数。“启用AI自动控制”是总开关；控制器每0.1秒更新分析和行为，并在有效受击时立即更新。

控制器的 `GetCurrentAnalysisDecision`（获取AI分析决策）返回是否有分支、入口类型及入口／状态／阶段标识；`OnAIAnalysisDecisionChanged`（AI分析决策变化）广播选择变化。执行器完成一次性受击分支后调用 `CompleteAttackedResponse`（完成AI受击响应）。`GetCurrentBehaviorAction`（获取当前AI行为）与 `OnAIBehaviorActionChanged`（AI行为变化）提供当前叶行为，移动和技能释放通过角色现有组件驱动动画。

视觉、听觉按各自记忆时间保存感知位置；持续可见的视觉可以刷新位置，声音及失去视觉的目标使用最后已知位置。新模式以最近的已知敌人作为分析目标，同距时按对象标识稳定选择。有效受击来自项目角色的实际承伤通知，没有攻击者对象也能触发；被忽略或无有效承伤的通知不触发。停止占有角色会清除本控制器的目标记忆、会话和定时更新。

## 感知能力

| 分组 | 参数 | 默认值 |
| --- | --- | --- |
| 视觉 | 启用视觉 | 开启 |
| 视觉 | 发现距离／丢失目标距离 | 30米／35米 |
| 视觉 | 视野半角 | 60度，即总视角120度 |
| 视觉 | 目标记忆时间 | 5秒 |
| 听觉 | 启用听觉 | 开启 |
| 听觉 | 听觉距离 | 20米 |
| 听觉 | 声音记忆时间 | 3秒 |
| 目标筛选 | 敌对／中立／友方 | 开启／关闭／关闭 |

目标筛选由视觉与听觉共用，敌我关系沿用项目阵营规则，不在此资产重新定义。可以关闭所有目标类别，也可以同时关闭视觉与听觉。关闭感知时保留并禁用编辑相关数值，重新启用后恢复使用。

已启用感知的距离必须为正有限值，丢失目标距离不能小于发现距离；视野半角允许0～180度；记忆时间为非负有限值，0表示不因超时遗忘刺激，不表示始终能看到或听到目标。面板独立显示感知校验结果，未填写行为ID不会遮蔽感知错误。暂未提供状态级覆盖或场景实例覆盖。

## 状态与阶段

状态包含闲置、巡逻、警戒、战斗、逃跑。对应阶段只接受该状态支持的行为。

状态与阶段目前都只有生命值限制条件，采用归一化闭区间：`0.5～0.6` 表示包含 50% 与 60% 两端。阶段区间必须完整落在所属状态区间内，两层条件同时生效。从状态拖出新阶段时，阶段先继承状态区间，再按需收窄。

例如战斗状态设为 `[0, 1]`，可以创建“常规”“半血”“濒死”三个战斗阶段，分别配置近战、远程技能和最终技能。区间重叠时按阶段排列序号选择；没有不可逆阶段锁定。技能本身的可打断时机需要由执行消费者提供，不由生命区间隐式决定。

## 行为参数

| 状态 | 行为 | 当前配置 |
| --- | --- | --- |
| 闲置 | 待机 | 等待时间；0 表示维持待机 |
| 巡逻 | 定点巡逻 | 点位 ID、到点等待时间；范围来自点位 |
| 巡逻 | 路线巡逻 | 路线 ID、往返／循环、到点等待时间 |
| 警戒 | 警戒 | 面朝敌人，保持最小／最大距离 |
| 战斗 | 释放近战技能 | 技能物品 ID、接近后的释放距离 |
| 战斗 | 释放远程技能 | 技能物品 ID、最小／最大释放距离 |
| 战斗 | 释放buff技能 | 技能物品 ID；原地释放 |
| 战斗 | 防卫 | 面朝敌人，保持最小／最大距离，不释放技能 |
| 逃跑 | 随机逃跑 | 每次远离敌人的目标距离；反复选导航点 |
| 逃跑 | 定点逃跑 | 点位 ID；进入点位范围即视为到达 |
| 逃跑 | 固定路线逃跑 | 路线 ID；按样条点顺序移动，到达终点结束本次逃跑 |

固定路线逃跑使用逃跑阶段排列第一的行为节点。将它排在该阶段首位并填写场景路线 ID 后，控制器会从首点依次前往末点；到达终点后结束本次受击响应。

距离字段单位为米，等待时间单位为秒。

## 场景导航对象

在关卡中添加 **AI路线** 或 **AI点位**，并为对象设置独立的 Gameplay Tag（游戏标签）ID。路线和点位分别使用 `AI.路线`、`AI.点位` 下的标签。行为节点引用相同 ID，不引用关卡对象的硬路径。

路线的局部点位以厘米定义折线路径，经过 Actor 的平移、旋转与缩放得到世界空间点位，编辑态显示配置颜色。点位只有一个中心和一个共享半径，50 米对应 5000 厘米。点位范围为世界空间球形区域，Actor 缩放不改变配置半径。

运行时导航缓存由游戏实例全局子系统持有。对象在 BeginPlay（开始运行）注册，在 EndPlay（结束运行）注销；按世界与精确标签查询，路线和点位分开索引。同一世界内同类 ID 重复会被拒绝，不覆盖已注册对象。缓存只保存弱引用，不延长关卡对象生命周期。

## 验证入口

编译 `LxARPGEditor Win64 Development` 后执行 `Automation RunTests LxARPG.AIBehaviorTree.+LxARPG.AIControlConfig.`，覆盖五入口图与共享连接、旧图迁移、参数和磁盘保存重载，以及优先级回退、距离滞回、受击响应、警觉恢复与会话隔离。角色控制器集成测试同属 `LxARPG.AIControlConfig.`。

控制器测试使用真实测试世界、角色与占有生命周期，通过公开感知报告接口及角色受击处理函数注入输入，并向真实感知组件注入刺激以检查更换角色时的缓存与待处理刺激清理；它验证来源记忆和分析接线，不代替真实关卡中的视线遮挡、噪声发射、导航到达、技能命中和动画表现测试。

追加 `-CreateAIBehaviorTreeExample` 可在不存在时创建 `/Game/AI/行为树示例`。追加 `-SmokeAIBehaviorTreeEditor` 并启用渲染，可打开真实编辑器并捕获 `Saved/Tests/AI控制配置编辑器.png` 与 `Saved/Tests/AI控制配置编辑器-五入口.png`。示例是待填写 ID 的设计模板，不是完整可执行战斗流程。测试若发现已有示例只加载检查，不修改或覆盖该资产。

`Automation RunTests LxARPG.AINavigation.` 验证导航注册、世界隔离和空间转换。仅在独立、启用渲染的 unattended 编辑器进程中追加 `-SmokeAINavigationPreview`，可用未保存的新空地图捕获未选中的路线与点位范围，输出 `Saved/Tests/AI导航预览.png`；不要在正在编辑用户地图的进程中开启此测试选项。


## 运动类型与运动能力

行为节点详情中的“运动类型”与动画蓝图共用 `ELxCharacterMotionType`（角色运动类型）。巡逻默认为低速移动，三种逃跑默认为高速移动，待机为闲置，警戒为警惕，近战技能、远程技能和防卫分别为近战攻击、远程攻击和防御；增益技能保留技能类型，死亡行为保留倒地类型。可逐节点改选；“无”表示按行为类型使用默认值。旧资产加载时自动补齐默认值，已配置值不会被覆盖。

为兼容已有动画资产，保留枚举内部名称和数值：`Move` 显示为低速移动，`Run` 显示为高速移动，`Attack` 显示为近战攻击；新增中速移动、警惕、远程攻击和防御，原有技能、受击、倒地和跳跃结束类型继续保留。

三档倍率统一在角色蓝图的“角色运动组件 → 移动速度配置”中设置，玩家和AI共用。默认低速0.5、中速1.0、高速1.5。最终速度（米/秒）= 基础移动速度 ×（1 + 移动速度加成）× 当前档位倍率；写入移动组件时再乘100换算为厘米/秒。示例：基础速度6米/秒、加成0.2、高速倍率1.5，最终10.8米/秒。非移动类型接近目标或调整距离时采用中速倍率，行为结束后恢复默认低速。属性刷新保留当前倍率，不会重复累乘。行为树资产的“运动能力”页仅显示旧配置供迁移参考，旧倍率不再参与运行时计算。

玩家默认低速移动，按住左Shift冲刺时使用中速，松开或取消输入时恢复低速。可在输入配置表中通过“冲刺”输入ID改键；旧表没有该行时自动补充默认按键。地面实际水平速度严格超过“基础移动速度 × 高速倍率”时，基础动画优先使用高速移动；该阈值不包含移动速度加成。静止、跳跃与滞空仍使用对应动画，不因速度上限较高而变为奔跑。

继承 `ULxAnimInstanceBase`（角色动画类型基类）的动画蓝图可读取“当前运动类型”；其他动画蓝图可从角色行为控制组件调用“获取当前运动类型”。该值表示当前行为节点的动作标识，巡逻等待或攻击接近期间仍保留节点标识，不等同于真实移动速度。已有基础动画信号及技能动作信号仍各自保留，便于后续分层混合。类型与倍率由服务端复制。

`Automation RunTests LxARPG.AIControlConfig.Movement` 验证角色配置应用、属性加成顺序、重复刷新、行为树切档及退出恢复；`LxARPG.Locomotion.Sprint` 验证默认按键、输入路由、按住与松开冲刺、改键保留、速度阈值和动画优先级。
