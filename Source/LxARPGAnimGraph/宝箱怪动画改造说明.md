# 宝箱怪动画

改造资产：`/Game/项目内容/实体资产/角色/测试怪物-宝箱怪/宝箱怪动画`。
参考资产：角色3的 `新角色动画蓝图`。普通宝箱怪、宝箱怪boss、测试角色-AI控制角色均沿用原来的动画类引用。

动画蓝图现在直接继承 `LxAnimInstanceBase`（角色动画类型基类），动画资源在动作节点中配置，不再依赖旧动画模板及重复的动画资产配置表。

```text
基础动作节点 → 基础动作缓存 ─┐
                            ├→ 动作骨骼分层混合 → 动作姿势混合堆栈 → 输出姿势
技能动作节点 → 技能动作缓存 ─┘
```

所有连接传递姿势。两个缓存均开启“无匹配时保持动作”；姿势混合堆栈沿用角色3的过渡时间 0.2 秒、最大过渡层数 4。

| 基础运动类型 | 宝箱怪动画序列 |
| --- | --- |
| 闲置 | ChestMonster_IdleNormal_ANIM（正常闲置） |
| 低速移动 | ChestMonster_WalkFWD_ANIM（向前行走） |
| 中速移动 | ChestMonster_Run_ANIM（奔跑） |
| 高速移动 | ChestMonster_Run_ANIM（奔跑） |
| 警惕 | ChestMonster_IdleBattle_ANIM（战斗闲置） |
| 受击 | ChestMonster_GetHit_ANIM（受击） |
| 倒地 | ChestMonster_Die_ANIM（死亡） |

中速、高速共用现有奔跑序列，播放速率仍由动画处理组件根据运动信号计算。资源没有专用跳跃动画，因此没有添加假跳跃节点。

| 技能动作节点 | 匹配规则 | 动画 |
| --- | --- | --- |
| 通用近战 | 近战攻击，技能ID留空 | ChestMonster_Attack01_ANIM（攻击01） |
| 通用远程 | 远程攻击，技能ID留空 | ChestMonster_Attack02_ANIM（攻击02，原技能槽资源作为备用远程动作） |
| 宝箱怪范围攻击 | 近战攻击，技能ID为 `物品.技能.范围效果.宝箱怪范围攻击` | ChestMonster_Attack01_ANIM（攻击01） |

当前宝箱怪范围攻击技能配置的动画运动类型为“近战攻击”，会优先选择填写了技能ID的近战节点。需要更换该技能动画时，只修改这个节点。

攻击节点均关闭“是否使用骨骼混合”，采用完整攻击姿势；均开启“是否接收动画通知”。分层节点使用宝箱怪自己的 `Head`（头部）骨骼、混合深度 1，作为未来局部动作启用骨骼混合时的配置，不引用角色3的人形脊柱。

两段攻击序列新增“技能事件”通知轨：

- 攻击01：第 11 帧，约 0.367 秒，`角色动作通知` 的“事件名称”为“技能释放”。
- 攻击02：第 10 帧，约 0.333 秒，同名通知。

以上帧号从 0 开始，按原序列 30 fps 计。初始位置参考了攻击序列的头部动作数据；实机手感可在动画序列时间轴拖动通知调整，不在技能上配置释放秒数。动作节点在非循环动画自然结束时上报“技能结束”，无须额外添加结束通知。

通知经过动画实例、动画处理组件、数据中转组件送往战斗组件，保留技能ID和本次播放编号；事件图无需为宝箱怪另接一套释放调用。

## 迁移与验证记录

`LxMimicAnimationCommandlet`（宝箱怪动画改造工具）默认只输出资产检查报告；`-Apply` 备份并迁移旧模板子类，目标已有动画图时拒绝覆盖；`-Verify` 只检查，不保存资产。

原始资产备份在 `Saved/MimicAnimation/Backup/`，包括宝箱怪动画蓝图和两段攻击动画。检查报告为 `Saved/MimicAnimation/Inspection.txt`；保存后重新加载的验证报告为 `Saved/MimicAnimation/Verification.txt`。

已编译 C++ 工具及目标动画蓝图，并在新编辑器进程重新加载，验证三个角色的动画绑定、七种基础动作匹配，以及通用近战、指定技能、相同技能连续重播、远程动作四轮真实动画更新。每轮均验证通知前无事件、释放与自然结束各一次、动画实例至数据中转组件的通知身份一致、末帧保持时不重复通知。

未进行编辑器画面或实机手感验收。无界面进程仍因项目已有的 `LxMaterialData` 类型重定向冲突返回退出码 1；迁移及验证工具自身均返回 0，日志分别包含 `MIMIC_ANIMATION_APPLY_OK` 与 `MIMIC_ANIMATION_VERIFY_OK`。该重定向问题在迁移前的只读检查中也存在。
