# 自动台地

预设位于 `/Game/项目内容/美术资产/自动化类型/台地`，包含“自动台地”和“圆角台地”。

## 用手柄调整长宽

在关卡视口选中台地后，点击台面边缘的红色长度点或绿色宽度点，再拖动出现的平移手柄。红色沿台地局部 X 轴改变长度，绿色沿局部 Y 轴改变宽度。中心保持不变，两侧对称伸缩；旋转台地后手柄仍沿台地自身方向工作。每次拖动支持一次撤销、重做，不会拉出曲线。

“台地长度”“台地宽度”以米显示，保留两位小数，也可在详情面板精确输入。蓝图可调用“设置台地长宽（米）”。旧关卡的厘米尺寸自动兼容，原尺寸接口仍保留。

拖动中显示带错缝铺砖、砖色差及连接开口的轻量模型。松开手柄仍保留轻量预览，保存或运行前才生成完整砖块、碰撞和静态网格/Nanite 数据。

## 石材表现

现有预设的砖缝已加宽至 0.03 米，采用清晰的浅冷灰缝色；砖面增加明度和少量冷暖变化，保留灰白、干净、明亮的预设风格。预览与完整版共享铺砖坐标，改变尺寸时砖块保持原有尺度，超大台地自动控制砖块数量。

“边石倒角”默认 0.02 米，为大块边石上沿生成真实斜面；设为 0 可关闭。轻量预览保留边石总体轮廓，完整倒角在保存或运行时生成。

## 验证入口

`LxARPG.World.StoneTerrace.Handles` 覆盖旋转后两轴拖动、微小位移累计、实时连接、撤销重做、米制精度及最终 Nanite 数据。`LxARPG.World.StoneTerrace.PavingAndBevel` 覆盖逐砖色差、砖缝坐标、真实倒角与极限小尺寸。

官方 MCP 脚本 `Source/LxARPGEditor/Scripts/调用台地工具.ps1` 的 `style` 阶段只更新已有预设；`demo`、`verify`、`capture` 使用独立的“台地演示”关卡进行保存重载和离屏渲染验收。
