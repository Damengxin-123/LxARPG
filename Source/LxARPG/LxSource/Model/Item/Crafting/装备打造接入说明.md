# 装备打造接入说明

## 使用与配置

新手村铁匠的原对话树增加“打造装备”选项，打开打造界面并展开角色背包。将背包或穿戴栏中的装备拖入放大的打造格子后选择操作。格子仅保留装备实例引用，关闭界面、取下装备均不会丢失或移动物品；背包排序后继续按实例 ID 定位。离开 NPC 范围或失去交互条件后不能继续操作。

界面蓝图：

- `/Game/项目内容/UI/角色UI界面/制造界面/装备打造`
- `/Game/项目内容/UI/角色UI界面/制造界面/打造格子`

运行逻辑由 `ULxEquipmentCraftingWidget`（装备打造界面）、`ULxCraftingGridWidget`（打造装备格子）提供，布局保存在上述蓝图，复用现有象牙面板、浅蓝物品格和中文字体。主布局管理器提供“注册制造界面”蓝图接口。界面由 `ULxManufacturingUIManager`（制造界面管理器）管理，交互取消和通用关闭入口统一释放页面及 NPC 服务。

`ALxPlayerCharacter`（玩家角色）默认挂载 `ULxItemManufacturingComponent`（物品制造组件）。组件提供放入、取下、查询报价、执行打造等蓝图接口，并广播“装备打造完成”。界面提供“打造显示更新”和“打造操作完成”蓝图事件。

其他 NPC 接入：在其交互组件启用“功能界面”，将“功能界面标识”选为“装备打造（强化与锻造）”，设置页面为“装备打造”，并在对话树中连接功能界面节点。在“装备打造加成”中配置：

- “成功率倍率”：默认 1，仅影响强化及增加词条。
- “金币消耗倍率”：默认 1，影响所有操作。最终金币向上取整；倍率为 0 时免费。

装备静态配置使用“固定普通词条”和“锻造词条池”。词条池留空时从已配置的属性数值修改、属性影响词条中选择。新增时排除已经拥有的词条 ID，包含基础词条。

## 装备与存档

装备运行时只使用基础、普通两类词条。基础词条每次从装备配置恢复，打造不能修改；旧锁定、特殊分类仅保留序列化兼容，装备加载时归为普通词条。普通装备最多 20 条普通词条，可减至 0 条。固定装备的普通词条来自静态配置，仅允许强化。静态配置中的空 ID 占位项被忽略；超过 20 条普通词条时只采用前 20 条，原配置不被改写。

强化度 `e` 使用比例存储，例如 `0.60` 表示 60%，允许超过 100%。普通词条保存未经强化的比例 `r`，最低为 0，允许超过 1（100%），例如 `1.25` 表示 125%。词条运行时生效比例为 `r × (1 + e)`；基础词条同样接受 `1 + e` 倍率。原始配置与存档比例不叠乘，反复读档不会累计放大。

角色的背包装备与穿戴装备集中保存在该角色记录的 `EquipmentInstances`（装备实例集合）中，槽位通过 GUID 引用。同一种装备 ID 的多件装备拥有独立身份和状态。每条实例记录包含装备 ID、强化度及普通词条 ID/生效比例，固定装备不保存普通词条。没有额外创建独立装备文件。

仓库、宝箱、有限库存商人内的装备状态保存在各自交互存档中，不加入玩家装备集合。跨容器移动及有限商品购买保留装备身份、词条和强化度；无限商品每次购买生成新实例身份。旧角色内联物品档、旧容器预设档保留读取兼容。

## 数值规则

令 `e` 为当前强化比例，`n` 为普通词条数，`s` 为 NPC 成功率倍率，`g` 为 NPC 金币倍率。

| 操作 | 最终概率 | 最终金币 |
| --- | --- | --- |
| 强化 | `clamp(max(0.01, 100^(-e)) × s, 0, 1)` | `ceil((1 + 49e) × g)` |
| 增加词条 | `clamp(max(0.01, 100^(-n/10)) × s, 0, 1)` | `ceil((1 + 4.9n) × g)` |
| 调整词条 | 每条独立 50% 提高、50% 降低 | `ceil(5g)` |
| 移除词条 | 从前往后逐条独立 50%，命中一次即停 | `ceil(5g)` |

概率下限 1% 作用于基础概率；NPC 倍率低于 1 时最终概率可低于 1%，高于 100% 时按 100% 处理。费用随强化或词条数线性增长。

| 强化度 | 基础成功率 | 基础金币 |
| --- | --- | --- |
| 0% | 100% | 1 |
| 30% | 25.12% | 16 |
| 60% | 6.31% | 31 |
| 100% | 1% | 50 |
| 200% | 1% | 99 |

强化成功随机增加 1～10 个百分点。失败时，操作前强化度不超过 30% 则不损失；超过 30% 则随机扣除 1～10 个百分点，可降到 30% 以下。

调整词条时，每个普通词条独立决定增减，再随机变化 0～20 个百分点，结果最低为 0%，不设 100% 上限；例如当前 100% 时可提高到 120%，当前 150% 时仍可继续提高或降低。增加词条时初始比例在 0%～100% 内随机，20 条时禁止新增。移除操作可能一条也没有移除；若有 n 条，至少移除一条的概率是 `1 - 0.5^n`。所有有效尝试都会收费，包括随机失败；无装备、固定装备尝试锻造、没有候选词条、数量上限、金币不足及服务失效均不会扣费。

稀有度按普通词条数计算，基础词条不计数：

| 装备类型 | 条数 | 稀有度 |
| --- | --- | --- |
| 普通装备 | 0～1 | 普通 |
| 普通装备 | 2～7 | 高级 |
| 普通装备 | 8～11 | 稀有 |
| 普通装备 | 12～20 | 神话 |
| 固定装备 | 0～7 | 传说 |
| 固定装备 | 8～20 | 史诗 |

## 验证与维护

`LxARPG.EquipmentCrafting` 自动化覆盖曲线边界、随机分布、固定装备限制、实例存档、跨容器状态、真实打造蓝图拖入、按钮扣费与服务失效。存档、交互及物品拖放回归同时检查旧路径。

编辑器资产工具位于 `LxEquipmentCraftingAssetLibrary`。脚本 `Source/LxARPGEditor/Scripts/装备打造工具.py` 通过虚幻 5.8 官方 ModelContextProtocol 和 ToolsetRegistry 注册工具，`调用装备打造.ps1` 调用检查、构建、接入、预览、测试步骤。重建界面会更新上述两份生成蓝图的布局；若已手工改过布局，应先保留修改。铁匠首次改动备份位于 `Saved/EquipmentCrafting/备份`。

2026-10-13 验证结果：虚幻 5.8 编辑器目标编译成功；装备打造、存档、交互与物品拖放共 27 项自动化通过，其中刷怪点身份测试包含一条预期警告。报告位于 `Saved/Automation/EquipmentCrafting/index.json`，实际装备界面预览位于 `Saved/EquipmentCrafting/实际装备/装备打造预览.png`。

另行运行的 `LxARPG.Save.InteractionMapPIEPersistence`（真实交互地图 PIE 存读档）测试在启动、流送或恢复阶段超时，尚未通过；其报告保留于 `Saved/Automation/EquipmentCrafting/map-regression.json`。因此上述 27 项通过不代表完整真实地图 PIE 流程已经验证通过。
